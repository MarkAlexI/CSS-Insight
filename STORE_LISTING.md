# Store listing copy for 1.22.2

Use the localized short descriptions below in the Chrome Web Store listing. The full descriptions can remain the localized marketing copy prepared for the previous release.

## English

Short description:

> CSS Insight - quick CSS inspection, analysis, editing and one-click copying on webpages. A practical tool for web developers.

Release notes:

> Added a visible inspection target, one-click reset to the active page, removable CSS previews, a localized update page and improved keyboard focus.

## Deutsch

Kurzbeschreibung:

> CSS Insight - CSS auf Webseiten schnell prüfen, analysieren, bearbeiten und mit einem Klick kopieren. Ein Tool für Webentwickler.

Versionshinweise:

> Neu sind ein sichtbares Inspektionsziel, das Zurücksetzen auf die aktive Seite mit einem Klick, entfernbare CSS-Vorschauen, eine lokalisierte Update-Seite und ein verbesserter Tastaturfokus.

## Español

Descripción breve:

> CSS Insight - inspecciona, analiza, edita y copia CSS en páginas web con un clic. Una herramienta práctica para desarrolladores web.

Notas de la versión:

> Se añadieron un objetivo de inspección visible, el restablecimiento a la página activa con un clic, vistas previas de CSS eliminables, una página de actualización localizada y un mejor foco de teclado.

## Українська

Короткий опис:
