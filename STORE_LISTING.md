# Store listing copy for 1.23.0

Use the localized short descriptions below in the Chrome Web Store listing. The full descriptions can remain the localized marketing copy prepared for the previous release.

## English

Short description:

> CSS Insight - quick CSS inspection, analysis, editing and one-click copying on webpages. A practical tool for web developers.

Release notes:

> Filter Declared Styles, Computed Styles, Media Rules and Keyframes instantly without querying the page again. Complete CSS blocks and enclosing at-rules stay intact, and Copy, Save and View More Details use the visible results.

## Deutsch

Kurzbeschreibung:

> CSS Insight - CSS auf Webseiten schnell prüfen, analysieren, bearbeiten und mit einem Klick kopieren. Ein Tool für Webentwickler.

Versionshinweise:

> Deklarierte und berechnete Stile, Media-Regeln und Keyframes lassen sich jetzt ohne erneute Seitenabfrage sofort filtern. Vollständige CSS-Blöcke und umgebende At-Regeln bleiben erhalten; Kopieren, Speichern und Weitere Details verwenden die sichtbaren Ergebnisse.

## Español
